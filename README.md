# מפת התרבות של קריית שמונה

פלטפורמה אינטראקטיבית המציגה את השחקנים, שותפי ההון והנכסים של מרחב התרבות בקריית שמונה,
ומצליבה אותם מול היעדים, האומדנים, המדדים והרמזור (הכוונה לפיתוח מקומי) של התוכנית העירונית.

מסמך עבודה של המכון הישראלי למדיניות תרבות ותנועת תרבות, עבור עיריית קריית שמונה.

## האתר

האתר מוגש ב-Firebase Hosting (פרויקט `iicp-ks-culture-map-714e8`, אתר `iicp-ks-culture-map`):

* https://iicp-ks-culture-map.web.app
* https://kiryat-shmona-agents.iicp.org.il (הדומיין של המכון)

פריסה: `firebase deploy --only hosting` מתיקיית הריפו (או `python deploy_site.py` מתיקיית
העבודה ב-OneDrive, שמעתיק, דוחף ל-git ופורס). הריפו ב-GitHub משמש לניהול גרסאות בלבד.

האתר מסומן `noindex` ו-`robots.txt` חוסם סריקה: הקישור מיועד להפצה ישירה לבעלי העניין,
לא לאיתור במנועי חיפוש. כדי לפתוח את האתר לאינדוקס יש למחוק את `robots.txt`
ואת השורה `<meta name="robots" content="noindex">` שב-`index.html`.

## קבצים

| קובץ | תוכן |
|---|---|
| `index.html` | האפליקציה: עיצוב, מנוע המפה וכל התצוגות |
| `data.js` | מודל התוכן: אזורים, אומדנים, מדדים, הרמזור, שחקנים, שותפי הון, נכסים |
| `geo.js` | גיאומטריית רקע מ-OpenStreetMap: רחובות, כבישים, נחלים, שטח בנוי (רישיון ODbL) |
| `build_offline.py` | מייצר קובץ HTML יחיד עצמאי לחלוטין לשליחה במייל, וגם ZIP |

## עדכון תוכן

עורכים את `data.js` בלבד. הכל נגזר ממנו: המפה, הכרטיסים, ההצלבה, הדירוג והפרופילים.

* ציוני אומדנים ומדדים: השדות `a` ו-`m` בכל שחקן, ערכים 1 עד 3.
* הרמזור: השדה `dev` בכל שחקן ושותף הון: `"g"` ירוק (מכוון פיתוח מקומי),
  `"o"` כתום (פוטנציאל), `"r"` אדום (מיקור חוץ).

לאחר עריכה: `git add data.js`, `git commit`, `git push`. האתר מתעדכן לבד.

## קובץ עצמאי לשליחה

```bash
python build_offline.py
```

מייצר `מפת התרבות - קריית שמונה.html`: קובץ אחד עם הגופנים מוטמעים, נפתח בלחיצה
כפולה בכל דפדפן בלי אינטרנט, עם מדיניות אבטחת תוכן החוסמת כל פנייה לרשת. הקבצים
הנוצרים אינם נשמרים בריפו.

## אבטחה

* אין קוד צד שלישי: הכל וניל JavaScript ו-SVG, ללא ספריות חיצוניות.
* Content-Security-Policy: באתר נטענים גופנים מ-Google Fonts בלבד; כל פנייה אחרת לרשת חסומה.
  בקובץ העצמאי נחסמת כל פנייה לרשת.
* אין איסוף מידע, אין עוגיות, אין טפסים. localStorage משמש רק לזכירת ערכת הצבעים.
